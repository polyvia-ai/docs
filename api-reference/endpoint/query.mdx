The Query endpoint lets you ask questions about your documents using natural language. You can query across your entire workspace or scope a query to a single document.

## Query Documents

### Endpoint

`POST /api/v1/query`

- **Without `document_id`:** Polyvia searches across all your completed documents and composes an answer with citations.
- **With `document_id`:** The answer is grounded in that specific document only (faster and more focused).

### Request Body

`application/json`

<ParamField body="query" type="string" required>
  Your natural-language question
</ParamField>

<ParamField body="document_id" type="string">
  Restrict the query to a single document. Omit to search across all completed documents.
</ParamField>

### Response

<ResponseField name="answer" type="string">
  The answer to your question
</ResponseField>

<ResponseField name="document_id" type="string">
  The document used to answer the query (present when querying a single document)
</ResponseField>

### Examples

<CodeGroup>
```bash Cross-document query
curl -X POST https://app.polyvia.ai/api/v1/query \
  -H "Authorization: Bearer poly_<your-key>" \
  -H "Content-Type: application/json" \
  -d '{"query": "What risks are mentioned across all reports?"}'
```

```bash Single-document query
curl -X POST https://app.polyvia.ai/api/v1/query \
  -H "Authorization: Bearer poly_<your-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "query":       "What is the executive summary?",
    "document_id": "k57abc123..."
  }'
```

```python Python
import httpx

HEADERS = {"Authorization": "Bearer poly_<your-key>"}
BASE    = "https://app.polyvia.ai"

# Cross-document query
resp = httpx.post(
    f"{BASE}/api/v1/query",
    headers=HEADERS,
    json={"query": "What risks are mentioned across all reports?"},
)
print(resp.json()["answer"])

# Single-document query
resp = httpx.post(
    f"{BASE}/api/v1/query",
    headers=HEADERS,
    json={
        "query":       "What is the executive summary?",
        "document_id": "k57abc123...",
    },
)
print(resp.json()["answer"])
```
</CodeGroup>

<ResponseExample>
```json Success
{
```

<Note>
Documents must have `status=completed` before they can be queried. Use the [Check Ingestion Status](/api-reference/endpoint/ingest) endpoint to confirm a document is ready.
</Note>
